# Jarvis Life V1
Assistant personnel intelligent avec une interface futuriste inspirée des assistants de science-fiction.
## Fonctionnalités prévues
- Interface moderne et responsive
- Conversation avec un assistant
- Gestion des tâches et des notes
- Comptes utilisateurs avec Supabase
- Sauvegarde des données
- Préparation à l'intégration d'une intelligence artificielle
## Technologies
- HTML5
- CSS3
- JavaScript
- Supabase Auth et Database
## Installation
1. Télécharge ou clone le projet.
2. Ouvre le dossier dans Visual Studio Code.
3. Configure les identifiants de ton projet Supabase dans `supabase.js`.
4. Lance l'application avec un serveur local, par exemple Live Server.
## Structure du projet
- `index.html` : interface principale
- `style.css` : design
- `app.js` : interactions de l'assistant
- `supabase.js` : configuration Supabase
## Sécurité
Ne publie jamais une clé secrète Supabase ou une clé privée d'API d'intelligence artificielle dans le code accessible au navigateur.
